How Bulk Upload Works

1. Download the template — row 1 is column headers, row 2 is field descriptions, row 3 is an example (delete rows 2–3 before importing your data).
2. Fill in one product per row. Required: name. Slug is auto-generated from name if left blank.
3. For jewel_type / jewel_sub1 / jewel_sub2 — use exact values from Jewelry Categories master.
4. For stone_name, metal_type, diamond_quality, labour_category — use exact names from Masters so IDs are resolved automatically.
5. Upload images to Cloudinary first, paste URL in image_url.
6. Save as .xlsx, drag onto zone below, preview, then click Import All.
